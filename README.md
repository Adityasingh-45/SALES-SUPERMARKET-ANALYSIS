# SALES-SUPERMARKET-ANALYSIS

## Project Overview
This project is a Power BI dashboard created to analyze supermarket sales performance and generate business insights.

## Dashboard Features
- Total Sales KPI
- Total Orders KPI
- Total Profit KPI
- Sales by Payment Mode
- Sales by Region
- Sales by Segment
- Monthly Sales Trend
- Monthly Profit Trend
- Sales by Category
- Sales by Sub Category
- Ship Mode Analysis
- State-wise Sales Visualization

## Tools Used
- Power BI
- Excel / CSV Dataset
- Data Cleaning
- Data Visualization
- Business Analysis

## Key Insights
- Identified top-performing regions
- Category-wise revenue analysis
- Profit trend by month
- Customer segment analysis
- Shipping mode performance tracking
